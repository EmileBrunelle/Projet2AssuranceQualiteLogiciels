# Projet 2 — Assurance qualité logiciels

*English follows.*

Application Java de gestion de factures pour un restaurant : import d'un fichier de commandes, calcul des taxes (TPS/TVQ), formatage et export de la facture en texte, avec une petite interface Swing. Le cœur du projet était la **qualité** : suite de tests **JUnit** couvrant les entités (`TestClient`, `TestFacture`, `TestPlat`) et l'importation (`TestImporterText`).

Projet réalisé en duo avec Philippe Viau, à l'hiver 2018, dans le cadre du cours **Assurance qualité des logiciels (420-4B4-MO)** du DEC en informatique de gestion (Collège Montmorency, 2016–2019). Le code est sur la branche `dev`. Archivé tel quel.

## Technologies

- **Java** (Swing pour l'interface)
- Tests **JUnit**

# Project 2 — Software Quality Assurance (English)

Java invoice-management application for a restaurant: imports an order file, computes sales taxes (GST/QST), formats and exports the invoice as text, with a small Swing UI. The heart of the project was **quality**: a **JUnit** test suite covering the domain entities (`TestClient`, `TestFacture`, `TestPlat`) and the import layer (`TestImporterText`).

Project done as a duo with Philippe Viau, in winter 2018, for the **software quality assurance course (420-4B4-MO, “Assurance qualité des logiciels”)** of my college diploma (DEC) in Information Technology (Collège Montmorency, 2016–2019). The code lives on the `dev` branch. Archived as is.

## Tech stack

- **Java** (Swing UI)
- **JUnit** tests
